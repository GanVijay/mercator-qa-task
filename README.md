# QA Automation Framework – Java | Selenium | Cucumber

## Overview
This repository contains a Cucumber BDD automation framework built using Java, Selenium WebDriver, JUnit, and Page Object Model (POM).  
It automates the SauceDemo scenario required in the QA task.

## Required 
- Java 17
- Maven

## How to Run
mvn clean test


## Framework Structure
(See folder tree in repository)

## Scenario
Automates:
- Login
- Select highest priced item
- Add to cart
- Verify correct item added
